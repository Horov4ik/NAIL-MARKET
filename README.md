# NAIL-MARKET Bot

Telegram-бот для прийому замовлень магазину матеріалів для манікюру.

## Як це працює

### Сторона клієнта

1. Пише боту `/start` — бачить кнопку «🛍 Створити замовлення».
2. Натискає кнопку → бот показує список категорій з каталогу (кнопками).
3. Обирає категорію → пише текстом, що саме хоче (назва, колір, артикул тощо).
4. Вказує кількість.
5. Вводить своє ПІБ.
6. Вказує телефон — або тисне кнопку «📱 Надіслати мій номер», або вводить вручну.
7. Одним повідомленням пише місто і номер відділення Нової пошти (наприклад: «Вінниця, відділення 15»).
8. Бачить підсумок замовлення і тисне «✅ Підтвердити» (або «❌ Скасувати», щоб почати заново).
9. Після підтвердження отримує повідомлення «Замовлення №N прийнято!».

На будь-якому кроці можна написати `/cancel`, щоб перервати оформлення.

### Сторона адміна (дружина)

- Одразу після підтвердження замовлення в чат адміну (за `ADMIN_IDS`) прилітає повідомлення:
  - номер замовлення,
  - ПІБ, телефон, місто/відділення НП,
  - категорія, товар, кількість,
  - хто оформив (`@юзернейм` або `id`, якщо юзернейму немає).
- Усі замовлення також зберігаються в `data/orders.json` — можна відкрити файл і подивитись історію.
- Каталог категорій адмін редагує сама, без втручання в код — команда `/admin` у чаті з ботом відкриває панель:
  - **📋 Переглянути каталог** — показує нумерований список категорій.
  - **➕ Додати категорію** — бот попросить написати назву, і вона одразу з'явиться в каталозі.
  - **➖ Видалити категорію** — показує список категорій кнопками, клік видаляє її.

Бот працює через *polling* (сам постійно запитує Telegram, чи є нові повідомлення), тому щоб він відповідав клієнтам — процес `python bot.py` має бути запущений весь час (див. розділ хостингу нижче, якщо треба, щоб він працював без твого комп'ютера).

## Запуск

### 1. Отримати токен бота
У Telegram напиши **@BotFather** → `/newbot` → вибери ім'я → отримай токен (виглядає як `123456789:AAExxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx`).

### 2. Дізнатись свій Telegram ID
Напиши **@userinfobot** у Telegram — він покаже твій id. Це буде `ADMIN_IDS` (можна кілька через кому, якщо адмінів декілька).

### 3. Налаштувати проєкт
```
git clone https://github.com/Horov4ik/NAIL-MARKET.git
cd NAIL-MARKET
```
Скопіюй `.env.example` у `.env` і встав свої значення:
```
BOT_TOKEN=123456789:AAExxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
ADMIN_IDS=111111111
```

### 4. Встановити залежності
Потрібен Python 3.10+.
```
pip install -r requirements.txt
```

### 5. Запустити
```
python bot.py
```
У консолі має з'явитись `Бот запущено.` — після цього бот вже відповідає в Telegram.

Щоб зупинити — `Ctrl+C`.

## Де зберігаються дані

- `data/categories.json` — список категорій каталогу (редагується через `/admin` у боті, руками правити не треба).
- `data/orders.json` — усі замовлення з історією.

## Де захостити безкоштовно, щоб бот працював постійно

Бот працює через *polling* — тобто це процес, який має бути запущений весь час. Просто закрити консоль на своєму комп'ютері не вийде, бот тоді вимкнеться. Ось два робочі безкоштовні варіанти.

> ⚠️ Умови безкоштовних тарифів у хмарних провайдерів час від часу змінюються, тому перед реєстрацією варто звіритись з актуальними умовами на сайті.

### Варіант 1 (найпростіший, на довгий час): Replit + UptimeRobot

Найшвидше піднімається, але Replit іноді "засинає" без пінгів — тримаємо його активним безкоштовним пінгером.

1. Зареєструйся на [replit.com](https://replit.com), створи новий Repl → Import from GitHub → встав посилання на `https://github.com/Horov4ik/NAIL-MARKET`.
2. У вкладці **Secrets** (значок замка́ ліворуч) додай змінні середовища замість `.env`:
   - `BOT_TOKEN` = токен бота
   - `ADMIN_IDS` = твій id
3. Replit "засинає" без вхідного HTTP-трафіку, а наш бот не приймає HTTP-запити — тому додай малий веб-сервер, який тримає Repl живим. У `bot.py` перед `if __name__ == "__main__":` встав:
   ```python
   from flask import Flask
   from threading import Thread

   web_app = Flask(__name__)

   @web_app.route("/")
   def home():
       return "Бот працює"

   def run_web():
       web_app.run(host="0.0.0.0", port=8080)

   Thread(target=run_web).start()
   ```
   і додай `flask` у `requirements.txt`.
4. Натисни **Run** — Replit покаже посилання на веб-сторінку (щось на кшталт `https://nail-market.твій-юзернейм.repl.co`).
5. Зареєструйся на [uptimerobot.com](https://uptimerobot.com) (безкоштовно) → **Add New Monitor** → тип HTTP(s) → встав те саме посилання → інтервал перевірки 5 хвилин.
6. UptimeRobot тепер регулярно "стукатиме" в Repl, не даючи йому заснути, і бот працюватиме постійно.

Мінус: залежить від Replit + UptimeRobot одночасно, зрідка можуть бути короткі перебої в роботі — для домашнього магазину це не критично.

### Варіант 2 (надійніше, справді безкоштовно назавжди): Oracle Cloud Free Tier

Це справжній безкоштовний сервер (VPS), який ніколи не вимикається і не залежить від сторонніх пінгерів. Налаштування довше, зате найнадійніше.

1. Зареєструйся на [cloud.oracle.com](https://cloud.oracle.com) (Always Free tier). Картка потрібна лише для верифікації, з Always Free ресурсів гроші не знімають.
2. У консолі: **Compute → Instances → Create Instance**.
   - Image: **Ubuntu** (остання LTS-версія)
   - Shape: обери позначену як **Always Free eligible** (наприклад `VM.Standard.E2.1.Micro` або Ampere A1)
   - При створенні збережи приватний SSH-ключ (`.key` файл) — він знадобиться для підключення.
3. Після створення скопіюй публічну IP-адресу інстансу.
4. Підключись по SSH (з PowerShell або Git Bash):
   ```
   ssh -i шлях/до/ключа.key ubuntu@ТВОЯ_IP_АДРЕСА
   ```
5. На сервері встанови Python і git:
   ```
   sudo apt update
   sudo apt install -y python3-pip python3-venv git
   ```
6. Клонуй репозиторій і налаштуй проєкт:
   ```
   git clone https://github.com/Horov4ik/NAIL-MARKET.git
   cd NAIL-MARKET
   python3 -m venv .venv
   source .venv/bin/activate
   pip install -r requirements.txt
   nano .env
   ```
   У `nano` встав:
   ```
   BOT_TOKEN=твій_токен
   ADMIN_IDS=твій_id
   ```
   Збережи (`Ctrl+O`, `Enter`, `Ctrl+X`).
7. Щоб бот працював постійно й автоматично перезапускався після збою чи перезавантаження сервера, зроби його systemd-сервісом:
   ```
   sudo nano /etc/systemd/system/nailmarket.service
   ```
   Встав (заміни шляхи, якщо клонував не в `/home/ubuntu`):
   ```ini
   [Unit]
   Description=NAIL-MARKET Telegram Bot
   After=network.target

   [Service]
   User=ubuntu
   WorkingDirectory=/home/ubuntu/NAIL-MARKET
   ExecStart=/home/ubuntu/NAIL-MARKET/.venv/bin/python bot.py
   Restart=always

   [Install]
   WantedBy=multi-user.target
   ```
8. Запусти сервіс:
   ```
   sudo systemctl daemon-reload
   sudo systemctl enable nailmarket
   sudo systemctl start nailmarket
   ```
9. Перевірити статус і логи:
   ```
   sudo systemctl status nailmarket
   journalctl -u nailmarket -f
   ```

Тепер бот працює 24/7, безкоштовно, і сам піднімається після перезавантаження сервера чи падіння процесу.

## Часті проблеми

- **`BOT_TOKEN не знайдено`** — не створений `.env` файл або в ньому немає `BOT_TOKEN`.
- **Сповіщення адміну не приходять** — перевір, що `ADMIN_IDS` заповнений правильним Telegram id, і що ти вже хоч раз написав своєму боту `/start` (Telegram не дозволяє боту писати першим, поки користувач не почав діалог).
- **Бот не відповідає** — переконайся, що `python bot.py` досі запущений (при закритті консолі бот вимикається; для постійної роботи потрібен хостинг).
